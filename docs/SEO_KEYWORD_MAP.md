## Current structural limitations and next opportunities

1. The current public catalog route is /products; category selection is currently query/filter driven rather than a dedicated crawlable category landing page.
2. The sitemap currently contains the four public static pages and active product detail URLs. It does not create independent category URLs.
3. A future category landing page should be created only when the category has active products and enough unique content to be useful.
4. Do not create thin pages for every spelling variation, city, size, color, or keyword.
5. Product detail pages should remain the primary targets for specific product/model searches.
6. Add buying guides only when the store can provide accurate, original advice.
